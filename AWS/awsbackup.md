# AWS Backup  
AWS Backup is a fully managed backup service by AWS that lets you automate and centralize backups across various AWS services — such as EC2, RDS, EFS, DynamoDB, EBS, and others — all from a single place.

# 🧩 What AWS Backup Does

It helps you:

1. **Create**, schedule, and manage backups automatically  
2. **Restore** data quickly across AWS services  
3. **Enforce** backup policies for compliance and governance  
4. **Centralize** backup management across multiple AWS accounts and regions
