# 🔐 What is SSL/TLS?

SSL (Secure Sockets Layer) and TLS (Transport Layer Security) are security protocols used to encrypt data between:

- Browser ↔️ Website  
- Client ↔️ Server  
- Service ↔️ Service (APIs, microservices)

# 🧠 Why do we need SSL/TLS?

**Without SSL/TLS:**

- Your password can be read in plain text  
- Hackers can intercept or modify data  
- Identity of the server cannot be verified  

With SSL/TLS:

- Data is encrypted   
- Client knows it is talking to the real server (via certificate)  
- Prevents Man-in-the-Middle attacks  
- Builds trust (browser shows 🔒 lock)
